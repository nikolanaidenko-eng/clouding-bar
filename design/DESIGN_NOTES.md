# Clouding Bar — утверждённый дизайн (для Claude Code)

Макеты: файлы `*.dc.html` в этой папке (HTML + inline CSS, логика состояний в `<script type="text/x-dc">`). Это **источник правды** по цветам, размерам, отступам и анимациям: бери значения оттуда, не придумывай. Файлы не открываются как обычные страницы (нужен рантайм холста), читай их как код. Живой холст: Claude Design, артефакт «Clouding Bar UI» у пользователя.

## Стиль
- macOS, тёмная тема, нейтральные серые. Цвет только для состояния.
- Шрифт: системный (SF Pro), цифры `tabular-nums` (`.monospacedDigitSystemFont`). Моно: SF Mono для команд.
- Материал виджета: полупрозрачный фон rgba(40,40,42,0.78) + blur 28 + saturate 160% (`NSVisualEffectView`, `.hudWindow`/`.popover`), обводка 0.5 px rgba(255,255,255,0.14), радиус 18 (панель) / 22 (пилюля), тень 0 16 40 rgba(0,0,0,0.4).
- Токены: Desktop #1B1B1D · Material #28282A · Control #3A3A3C · Text #F5F5F7 · Secondary #A1A1A6 · Action #0071E3 · Warning #FF9F0A · Critical #FF453A · Deny-текст #FF6961 · трек полосы rgba(255,255,255,0.12) · заливка полосы #E5E5EA.
- Пороги полос: < 70% нейтральная, 70–90% оранжевая, ≥ 90% красная.
- Кликабельные зоны ≥ 44 pt.

## Анимации (кривая cubic-bezier(.2,.8,.2,1))
- Заполнение полосы: 900 мс от 0, при появлении и при изменении значения.
- Пилюля появляется: 220 мс, scale 0.9 → 1 + opacity.
- Панель раскрывается: 280 мс, translateY −6 → 0, scale 0.97 → 1, origin top‑right.
- Кнопки запроса на Touch Bar: въезд справа 260 мс.
- «Ждёт тебя»: точка #FF9F0A пульсирует 1.4 с (opacity 1 ↔ 0.35). Выключается в «Не беспокоить».
- Контекст ≥ 90% на Touch Bar: полоса «дышит» 2 с.
- Учитывать системную настройку «Reduce motion».

## Персонаж (`Mascot.dc.html`)
Свой, не персонаж Anthropic. Светлый округлый «камешек» (#ECEAE5), глаза‑овалы. Вектор, SVG‑анимации:
- **sleep**: тусклый (#B8B6B1), глаза‑дуги, дыхание 3.6 с, всплывающая «z».
- **work**: прыжок 0.7 с, моргание раз в 3.4 с, три точки «печатает» над головой.
- **wait**: покачивание ±7° 1.4 с, оранжевый значок «!» пульсирует.
Отдать в Swift как SVG/Lottie или нарисовать через `CAShapeLayer` с теми же таймингами.

## Touch Bar (2x: 2170×60 px = 1085×30 pt)
- Порядок: системный ✕ · esc · персонаж · **Session** · **Context** · кнопки.
- Session (flex 3) и Context (flex 2) занимают **всё свободное место** и сжимаются по числу кнопок:
  - много места: «Session 42% · 1:23» / «Context 31%»;
  - меньше: «5h» / «Ctx»;
  - мало: только проценты, таймер скрыт.
  Логика: `TB-Normal.dc.html`, `renderVals()`.
- Токенов на Touch Bar нет (они в виджете).
- Запрос разрешения: «Run `команда`» + Allow (синяя) / Always / Deny (красный текст).
- Вопрос: варианты + «Other…» → режим ввода (`TB-Typing`): полосы сжимаются в две мини‑полоски, поле занимает остаток, шрифт 26 → 22 → 19 по длине текста, дальше прокрутка; Send + микрофон.
- Порог контекста: Context красный, кнопки «Compact» (синяя) и «Later».

## Плавающий виджет
- По умолчанию **пилюля** в правом верхнем углу. Наведение → раскрывается панель 320 pt; мышь ушла → сворачивается.
- Пилюля: персонаж + мини‑полоса + Session %. По желанию всегда видны: **контекст**, **время до сброса**, **траты API** (настройка «Always show in pill»).
- Когда Claude ждёт: пилюля сама показывает «Needs your OK» + пульс, затем раскрывается в карточку запроса.
- Панель: шапка (персонаж, статус, проект, свернуть) · Session (%, полоса, «Resets in …») · Context (%, полоса, «in · out» токены) · ряд кнопок · «N sessions ›» + микрофон.
- Список сессий (опционально): отдельный экран, строки с персонажем, статусом, % контекста; клик → окно VS Code.
- Нет сессии: спящий персонаж + «последний известный» лимит серым с временем давности.

## Настройки (`Settings.dc.html`, окно 560×560)
Переключатель вкладок в шапке: **General · Buttons · Cowork · Stats**.
- General: Touch Bar (автоопределение), виджет, автозапуск, «Always show in pill» (Context / Reset time / API cost), «More options» раскрывается (галочки: предупреждение о контексте 80%, список сессий, не беспокоить, стоимость, модель, ±строки, git, субагенты).
- Buttons: **живое превью Touch Bar** сверху (полосы сжимаются при добавлении), список кнопок, «+ / −», при добавлении имя сразу появляется на превью (длинное → мельче шрифт → «…»), профиль по проекту.
- Cowork: сегмент Off / Thresholds / Every reply + пояснение; «Live limit via claude.ai» → «Set up…» раскрывает предупреждение и поле ключа.
- Stats: заголовок‑вывод недели, тепловая карта дни × часы (серые оттенки, оранжевым часы упора в лимит, появление волной), полоса долей по проектам.
